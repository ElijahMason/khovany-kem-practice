Use

Run a session from this sheet. Open on the queue. Leave with a written decision or a posted missing fact.

  1. 01

    Open on the queue

    Put the queue in front of the room. Do not open on a slide.

    Owner
    The person running the session.
    Done when
    Every open line is visible, with one name.

  2. 02

    Take the first blocked line

    The name on that line says what would move it.

    Owner
    The name written on the line.
    Done when
    The room has heard the block in one pass.

  3. 03

    Write the decision or the gap

    A decision is a sentence. If you cannot write it, write the missing fact, its owner, and when it will be posted.

    Owner
    One name, recorded in the log.
    Done when
    The log has the sentence or the gap.

  4. 04

    Read the floor note

    A desk, bench, or piece of hardware that blocks a step is posted with the queue, not after the session.

    Owner
    Khovany Kem, when he is in the session.
    Done when
    The blocked walk is moved or posted.

Close

Close a session that starts to wander. Wandering feels busy. It leaves the queue where it was.
