Use

Walk the room in this order. The drawing is a type, not a survey of a finished office. Khovany Kem places desks and hardware so the path matches the map. He does not install furniture as a trade.

  1. 01

    Door

    Enter here. The first thing you can read is the queue, not a person.

    Check
    The queue faces the path.

  2. 02

    Queue

    Read it without opening a laptop to hunt for a file. If you cannot point at a line, it is not posted.

    Check
    Owner and next decision are on the line.

  3. 03

    Owner

    Walk to the name on the current step. That walk is short. A long walk means the desk is in the wrong place.

    Check
    One desk, one active step.

  4. 04

    Hardware

    Printer, bench, screen, labeler: keep it with the step that uses it. A far closet adds a walk the map did not ask for.

    Check
    The tool is in reach of the step.

  5. 05

    Decision table

    Write the log here, with the queue still in sight. If the table cannot see the queue, people talk from memory.

    Check
    The queue is readable from the table.

When the map changes

Move the room. Do not keep an older layout and then buy a tool to cover the extra walk.
