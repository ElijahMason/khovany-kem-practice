Purpose

This sheet states the practice. Khovany Kem holds the project and the operating cadence. He includes the room, because a path you cannot walk is a process people will drop.

In scope

01
Project leadership. He holds the sequence, the owners, and the decisions that are still open.
02
Operations design. He draws where work changes hands, and where a handoff should stop.
03
Process maps. Steps, one owner on each step, and the queue, on one sheet.
04
Office layout for flow. Desks, benches, and hardware follow the map.
05
Tooling recommendations. A tool stays when it removes a handoff you can name.

Out of scope

He does not install furniture as a trade. He does not add a tool whose only effect is a louder queue. He does not count a meeting that ends in a recap.
